# Mad Libs Story Generator

## Description
This Python program generates funny and creative stories based on words entered by the user.

## Features
- Provides three different story templates.
- Allows users to choose a template.
- Requests words such as nouns, verbs, adjectives, colors and numbers.
- Generates a unique story using the entered words.
- Handles invalid user input.
- Prevents empty text input.
- Validates numeric input.

## How to Run
1. Make sure Python 3 is installed.
2. Download or clone the project.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python station_proj1.py
```

## How to Use
1. Run the program.
2. Choose one of the three available templates.
3. Enter the requested words.
4. The program generates and displays a story.

## Error Handling
- Invalid template choices are rejected.
- Non-numeric values are rejected when a number is required.
- Empty text inputs are not accepted.
- The program asks the user to enter valid data again.

## Technologies
- Python 3
